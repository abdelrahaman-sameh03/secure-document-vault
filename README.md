\# Secure Document Vault System



Secure Document Vault is a secure web-based platform that allows users to upload, store, encrypt, sign, verify, download, and manage digital documents.



\## Features



\- User registration and login

\- Password hashing using bcrypt

\- Password policy validation

\- JWT-based authentication

\- Role-Based Access Control: Admin, Manager, User

\- GitHub and Google OAuth login

\- Two-Factor Authentication using TOTP

\- Secure document upload

\- AES-256-GCM document encryption

\- SHA-256 hash generation

\- RSA digital signature

\- Integrity verification

\- HTTPS support using local SSL certificate

\- Admin panel with system logs

\- Manager document review page



\## Requirements



\- XAMPP

\- PHP 8+

\- MySQL / MariaDB

\- OpenSSL extension enabled

\- cURL extension enabled
